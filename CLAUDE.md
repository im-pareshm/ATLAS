# CLAUDE.md

This project's guidance for coding agents lives in [AGENTS.md](AGENTS.md) — project
status, commands, the money-math and recurring-generation architecture, the
source-of-truth docs, the tech stack, the architectural decisions to preserve, the
data model, the UI spec, and the testing setup. It applies to Claude Code exactly
as written; read it first.

This file exists only so a tool that specifically looks for `CLAUDE.md` (rather
than the newer, tool-agnostic `AGENTS.md` convention) still finds guidance here.
There is nothing Claude-Code-specific beyond what AGENTS.md already says — if you
edit the guidance, edit AGENTS.md, not this file, so the two never drift apart.
